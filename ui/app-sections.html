Watch a page

It's checked every 3 hours, or as set in Changedetection.io (Settings, or the watch's own Edit page), where you can also narrow it to part of the page.

Pages on your own network

Changedetection.io refuses addresses on your own network (192.168…, 10…, this Synology) unless you allow them — a guard for servers shared with strangers. Allow them to watch your router's or printer's pages, or other apps on this NAS.

Browser for JavaScript pages

Most pages are fetched directly, which is quick and light. Pages that build their content with JavaScript (many shops, single-page apps) need a real browser: Chrome in a second container, upstream's sockpuppetbrowser. It's about a 500 MB download and needs roughly 1 GB more memory while it runs.

Two ways to hear about a change: DSM's own notifications (the bell, and on to your phone or email through DSM's notification settings), and Changedetection.io's notifications, which go through Apprise to ntfy, email, Telegram, Discord and many more.

Password protection

Changedetection.io has one password for everyone, no user names. Changes here restart it for a few seconds.

Your own password

It isn't stored by the package: Changedetection.io keeps only a salted hash, as it does when you set it in its own Settings.

API key

The window reads your watches through Changedetection.io's API with the key in its Settings → API. If you make a new key there, the window picks it up by itself; if you turn the key off, the API is open to anyone who can reach it.
